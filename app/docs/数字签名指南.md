# 数字签名指南（消除 SmartScreen"未知发布者"提示）

当前安装包**未做代码签名**，用户下载后 Windows SmartScreen 会提示
"Windows 已保护你的电脑"，需要点"更多信息 → 仍要运行"。
做一次代码签名后即可消除该提示，正式分发建议完成本步骤。

## 一、选择签名证书

| 方案 | 价格 | 说明 |
|---|---|---|
| OV 代码签名证书 | 约 ¥800–3000/年 | 主流选择：DigiCert、GlobalSign、Sectigo；国内可买天威诚信、CFCA、沃通 |
| EV 代码签名证书 | 约 ¥3000–8000/年 | 需要硬件 USB Key；**签名后立刻获得 SmartScreen 信誉** |
| Azure Trusted Signing | 按签名次数计费（很便宜） | 微软云签名，无需买证书，适合开源/个人项目，用 GitHub Actions 集成很方便 |
| 自签名证书 | 免费 | 无法消除 SmartScreen 提示，仅适合内部测试 |

> 选 OV 即可满足大多数场景；SmartScreen 信誉会随着下载量/时间逐步建立，
> 初期少量用户仍可能看到提示。EV 和 Azure Trusted Signing 可立即生效。

## 二、准备签名工具（signtool）

三种获取方式（任选其一）：
1. 安装 **Windows SDK**（https://developer.microsoft.com/windows/downloads/windows-sdk/），
   signtool 位于 `C:\Program Files (x86)\Windows Kits\10\bin\<版本>\x64\signtool.exe`
2. 安装 **Visual Studio**（带"使用 C++ 的桌面开发"组件）
3. 单独下载 signtool（随 Windows SDK 一起提供，装完 SDK 直接用）

## 三、签名命令

### 1) 用 .pfx 证书文件签名（最常见）

```bat
set SIGNTOOL="C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\signtool.exe"
set CERT="D:\cert\my-cert.pfx"
set PASSWORD=你的证书密码

rem 签名启动器
%SIGNTOOL% sign /fd SHA256 /f %CERT% /p %PASSWORD% ^
  /tr http://timestamp.digicert.com /td SHA256 ^
  "DeepSeek Harness.exe"

rem 签名安装包（先编译再签名）
%SIGNTOOL% sign /fd SHA256 /f %CERT% /p %PASSWORD% ^
  /tr http://timestamp.digicert.com /td SHA256 ^
  "DeepSeekHarness-Setup-2.95.27.exe"
```

### 2) 用本机证书存储中的证书（按指纹）

```bat
rem 查看已安装证书的指纹
certutil -store My

%SIGNTOOL% sign /fd SHA256 /sha1 <证书指纹40位十六进制> ^
  /tr http://timestamp.digicert.com /td SHA256 ^
  "DeepSeek Harness.exe"
```

### 3) Azure Trusted Signing（推荐给开源项目）

1. 在 Azure 门户创建 Trusted Signing 账户与证书配置文件
2. 在 GitHub Actions 中安装 `Azure/trusted-signing-action@v0`，或在本地安装
   `az` CLI + `TrustedSigning` 扩展后使用 `az trustedsigning sign`
3. 官方文档：https://learn.microsoft.com/azure/trusted-signing/

## 四、验证签名

```bat
%SIGNTOOL% verify /pa /v "DeepSeek Harness.exe"
```

看到 `Signatures valid` 且包含时间戳即成功。也可右键 exe →
属性 → 数字签名 查看。

## 五、发布建议（GitHub Releases）

1. 依次执行：`build.ps1` 编译安装包 → 按上文签名 `DeepSeek Harness.exe`
   → 重新编译安装包 → 签名安装包（顺序：**先签 exe 再打包**，安装包里
   的 exe 就已带签名；安装包自身也要签）
2. 发布时同时提供安装包与 SHA-256 校验值，方便用户核对
   ```bat
   certutil -hashfile DeepSeekHarness-Setup-2.95.27.exe SHA256
   ```
3. 在 Release 说明中标注系统要求：Windows 10/11 x64

## 六、常见问题

- **时间戳是什么？** 签名时带上 `/tr`（RFC3161 时间戳），证书过期后签名依然有效。
- **SmartScreen 仍提示？** OV 证书的信誉需要时间；确认两个文件都签了名、
  时间戳有效；EV/Azure 方案可立即解决。
- **提示"发布者未知"？** 说明签名未成功或文件被修改，用 verify 检查。
