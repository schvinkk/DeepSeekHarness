# DeepSeek Harness 桌面版 —— 数字签名指南

未签名的安装包会触发 Windows SmartScreen「未知发布者」警告。正式分发前请按下述顺序签名。

## 前置条件

1. 一张代码签名证书（`.pfx`，含私钥）。可从 CA 购买 OV/EV 代码签名证书；EV 证书可立即获得 SmartScreen 信誉。
2. Windows SDK 的 `signtool.exe`（通常在 `C:\Program Files (x86)\Windows Kits\10\bin\<版本>\x64\signtool.exe`）。

为方便，先设环境变量（PowerShell）：

```powershell
$PFX   = "C:\path\to\your\cert.pfx"
$PWD   = Read-Host -AsSecureString "证书密码"
$ST    = "C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\signtool.exe"
$TSA   = "http://timestamp.digicert.com"   # 可信时间戳，签名不过期
```

## 签名顺序（重要：先内层，后外层）

### 1. 签启动器 EXE

```powershell
& $ST sign /f $PFX /p ([System.Net.NetworkCredential]::new('',$PWD).Password) `
    /tr $TSA /td sha256 /fd sha256 `
    "app\DeepSeek Harness.exe"
```

### 2. 编译安装包

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

> build.ps1 会把已签名的 `DeepSeek Harness.exe` 一起打进安装包。

### 3. 签安装包

```powershell
& $ST sign /f $PFX /p ([System.Net.NetworkCredential]::new('',$PWD).Password) `
    /tr $TSA /td sha256 /fd sha256 `
    "dist\DeepSeekHarness-Setup-3.0.0.exe"
```

### 4. 验证签名

```powershell
& $ST verify /pa "dist\DeepSeekHarness-Setup-3.0.0.exe"
```

## 校验清单

- [ ] `DeepSeek Harness.exe` 与安装包均已签名（`/pa` 验证通过）
- [ ] 签名含可信时间戳（断网也能验证）
- [ ] 新版本首次安装 SmartScreen 仍可能提示，EV 证书可缓解

> 注意：不要把 `.pfx` 或密码提交进 Git 仓库。签名在本机完成即可。
