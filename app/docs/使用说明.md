# DeepSeek Harness 桌面版 — 使用说明

DeepSeek Harness 是 DeepSeek 推出的 AI 智能体开发工具（Harness）。本安装包已将其
完整封装为**桌面客户端**：安装后无需安装 Node.js、无需配置任何开发环境，
双击图标即可打开使用，并支持**托盘常驻**与**开机自启**。

## 一、安装

1. 双击 `DeepSeekHarness-Setup-1.95.27.exe`（若提示"未知发布者"，点"仍要运行"）；
2. 按向导操作，**可选择自定义安装目录**（默认装到当前用户的程序目录，无需管理员权限）；
3. 可选勾选：
   - **创建桌面快捷方式**；
   - **开机自动启动服务**（后台常驻，打开即用；之后可在托盘随时开关）；
4. 完成后点击"立即启动"，稍候自动弹出客户端窗口。

> 首次启动会自动初始化，冷启动约 5–30 秒（取决于杀毒软件扫描），之后启动仅需数秒。

## 二、托盘常驻（核心功能）

启动后桌面右下角会出现**黑色鲸鱼托盘图标**，即使关闭客户端窗口，服务仍在后台运行：

| 操作 | 效果 |
|---|---|
| 双击托盘图标 | 打开客户端窗口 |
| 菜单·打开 DeepSeek Harness | 打开客户端窗口 |
| 菜单·重启服务 | 服务异常或想重置时使用 |
| 菜单·停止服务（释放内存） | 后台服务停止、内存释放；再打开客户端会自动重启 |
| 菜单·开机自启 | 勾选后登录 Windows 自动在后台启动服务（秒开） |
| 菜单·退出 | 停止服务并退出托盘程序 |

## 三、配置大模型

打开客户端后：

1. 点击左侧 **设置**（齿轮图标）；
2. 进入 **模型** 设置页，添加你的模型服务商：
   - **DeepSeek 官方**：填写 API Key（api.deepseek.com）；
   - **OpenAI 兼容服务**：填写 Base URL 与 API Key（如硅基流动、阿里云百炼等）；
   - 也支持 Anthropic、Google Gemini、Mistral 等多家服务商；
3. 保存后在输入框上方选择模型，即可开始对话。

## 四、日常使用

- **启动**：双击桌面图标（服务已在运行时直接打开窗口；托盘常驻时即时弹出）；
- **停止**：托盘菜单"退出"，或开始菜单"停止 DeepSeek Harness"快捷方式；
- **数据位置**：会话记录、配置、API 密钥保存在 `%USERPROFILE%\.dsh`，
  卸载程序**不会**删除它（重新安装后数据仍在）；
- **工作目录**：默认工作目录是你的用户主目录（`%USERPROFILE%`），
  智能体可以读写该目录下的文件。

## 五、性能说明（安装版 vs 网页版）

| 指标 | 实测值 |
|---|---|
| 冷启动（服务就绪） | 约 5–10 秒（首次安装后可能 20–30 秒，多为杀软扫描） |
| 热启动（二次启动） | 约 3–6 秒 |
| 后台常驻内存 | 约 170–200 MB |
| 客户端打开速度 | 服务常驻时**瞬时**（本地页面，无需联网） |

优化建议：
- **开机自启**：托盘菜单勾选后，服务随登录后台启动，打开客户端零等待；
- **省内存**：不使用时托盘菜单"停止服务（释放内存）"即可，再次打开自动重启；
- **首次卡顿**：多为 Windows Defender 首次扫描，可把安装目录加入杀软排除名单；
- 客户端使用**原生窗口**（系统 WebView2 内核，无浏览器外壳），窗口与任务栏统一显示
  黑色鲸鱼图标；页面全部由本地服务提供，比网页版省去了网络加载，交互更跟手。

## 六、常见问题

| 问题 | 解决办法 |
|---|---|
| 双击图标没反应 | 首次启动初始化需要几秒；查看 `%USERPROFILE%\.dsh\desktop.log` |
| 托盘图标不见了 | 重新双击桌面图标即可恢复托盘 |
| 端口 18632 被占用 | 关闭占用程序后重启；设置环境变量 `DSH_PORT` 可换端口 |
| 杀毒软件/系统提示 | 未签名所致，见安装目录 `docs\数字签名指南.md`；点"仍要运行"即可 |
| 服务异常退出 | 托盘菜单"重启服务"一键恢复 |

## 七、卸载

控制面板 → 程序 → 卸载 DeepSeek Harness（或运行安装目录下的卸载程序）。
卸载会移除开机自启注册项，但**保留**你的全部数据（`%USERPROFILE%\.dsh`）。

## 技术信息

- 内置运行时：Node.js v26.7.0（便携版，已随包附带，无需单独安装）
- 桌面版版本：**1.95.27**（内置 DeepSeek Harness `@deepseek-ai/dsh` 0.1.0-rc.6）
- 服务地址：`http://127.0.0.1:18632`（客户端专用端口，仅本机可访问，不与 dsh 命令行版冲突）
- 平台要求：Windows 10/11 64 位
