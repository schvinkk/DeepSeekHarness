# KK Go 桌面版 — 使用说明

KK Go 是封装 dsh 内核（`@deepseek-ai/dsh`）的桌面客户端，与手机端 dsh-Go 同属一套
「KK Go」品牌。本安装包已将其完整封装为**桌面客户端**：安装后无需安装 Node.js、
无需配置任何开发环境，双击图标即可打开使用，并支持**托盘常驻**与**开机自启**。

## 一、安装

1. 双击 `KKGo-Setup-x.y.z.exe`（若提示"未知发布者"，点"仍要运行"）；
2. 按向导操作，**可选择自定义安装目录**（默认装到当前用户的程序目录，无需管理员权限）；
3. 可选勾选：
   - **创建桌面快捷方式**；
   - **开机自动启动服务**（后台常驻，打开即用；之后可在托盘随时开关）；
4. 完成后点击"立即启动"，稍候自动弹出客户端窗口。

> 首次启动会自动初始化，冷启动约 5–30 秒（取决于杀毒软件扫描），之后启动仅需数秒。

## 一·补、你下载的这个包，已经内置了哪些功能（不用再装插件）

**你不用去任何开源平台找插件安装。** 这个安装包已经把 dsh 内核的整套常用官方能力内置好了，
装完、配好大模型，下面这些**全部直接能用**：

- **对话 / 角色 / 指令**：开箱即对话，支持自定义角色人设与 Agent 指令
- **跑命令**：PowerShell（Windows 自动启用）
- **文件读写 / 搜索**：能操作你本机文件（tool-fs、tool-fs-search）
- **定时任务 / 日程 / 目标 / 规划模式**：长任务、计划类工作（tool-jobs、tool-schedule、goal、plan-mode）
- **技能**：内置技能加载（tool-skill、文件系统技能）
- **长对话自动压缩**：上下文不会爆（compaction）
- **子代理 / 工作流**：多代理协作（subagent、workflow）
- **提问 / 待办 / 结果展示**：交互式协作（ask-user、todo、present）
- **联网**：网页获取与搜索（tool-web）
- **办公文档**：处理文档（tool-office）
- **插件管理器**：想在界面内加/管更多插件，用它（tool-plugin-manager），非必须

> 唯一要你自己做的：打开软件 →「设置 → 模型」→ 填上你的大模型 API Key（DeepSeek /
> OpenAI 兼容 / Anthropic / Gemini 等），保存后就能开始用了。

## 一·补2、软件更新了怎么办（覆盖升级，数据不丢）

**不需要卸载、不需要手动搬数据。** 只要你手上的版本比 GitHub 最新的小，按这个做，
过程和装普通软件完全一样——**直接盖在原来上面**：

1. **判断要不要更新**：托盘右键看版本号，或看安装目录 `docs`；比 GitHub 最新版小就更新。
2. **下载最新版** `KKGo-Setup-x.y.z.exe`（浏览器提示"未知发布者"就点"仍要运行"）。
3. **直接双击新版安装包**：
   - 安装器会识别到"已安装"并提示升级，一路点"下一步"即可；
   - **会直接覆盖旧版本**，不会变成第二个软件；
   - 安装位置、开机自启、桌面快捷方式、防火墙规则、以及你的全部数据（会话/配置/API 密钥）**自动保留**。
4. **点"立即启动"**，秒开，数据无缝衔接。

> 一句话：**双击新版 → 一路"下一步" → 数据自动保留 → 完成。** 旧版被自动覆盖。

## 二、托盘常驻（核心功能）

启动后桌面右下角会出现**黑色鲸鱼托盘图标**，即使关闭客户端窗口，服务仍在后台运行：

| 操作 | 效果 |
|---|---|
| 双击托盘图标 | 打开客户端窗口 |
| 菜单·打开 KK Go | 打开客户端窗口 |
| 菜单·重启服务 | 服务异常或想重置时使用 |
| 菜单·停止服务（释放内存） | 后台服务停止、内存释放；再打开客户端会自动重启 |
| 菜单·开机自启 | 勾选后登录 Windows 自动在后台启动服务（秒开） |
| 菜单·退出 | 停止服务并退出托盘程序 |

## 三、配置大模型

打开客户端后：

1. 点击左侧 **设置**（齿轮图标）；
2. 进入 **模型** 设置页，添加你的模型服务商：
   - **DeepSeek 官方**：填写 API Key（api.deepseek.com）；
   - **OpenAI 兼容服务**：填写 Base URL 与 API Key（如硅基流动、阿里云百炼等）；
   - 也支持 Anthropic、Google Gemini、Mistral 等多家服务商；
3. 保存后在输入框上方选择模型，即可开始对话。

## 四、日常使用

- **启动**：双击桌面图标（服务已在运行时直接打开窗口；托盘常驻时即时弹出）；
- **停止**：托盘菜单"退出"，或开始菜单"停止 KK Go"快捷方式；
- **数据位置**：会话记录、配置、API 密钥保存在**数据目录**里（默认放**非 C 盘**的 `KK Go Data` 文件夹，
  例如 `D:\KK Go Data`；可托盘右键「更改数据目录」改到任意盘），卸载程序**不会**删除它（重装/升级后数据仍在）；
- **工作目录**：默认工作目录是你的用户主目录（`%USERPROFILE%`），
  智能体可以读写该目录下的文件。

## 四·补、桌面端和网页端的关系（一个内核，两种入口）

**这是理解本软件最关键的一点**：桌面客户端和你浏览器里的网页端，**不是两套东西**，
而是**同一个本地服务、同一份数据、同一套插件**的两种外壳：

- 桌面窗口只是一个原生外壳（WebView2），它打开的页面就是本地服务
  `http://127.0.0.1:18632/?token=...` 提供的**完整 KK Go 界面**；
- 你在浏览器里打开同一个地址，看到的是**一模一样的界面、一样的会话列表、一样的插件**——
  因为是同一个服务在提供页面，功能、插件、会话、配置、API Key **完全联通、实时同步**；
- 两边可以**来回切换**：桌面窗口里聊到一半，去浏览器打开同一地址接着聊；
  反之亦然。数据只有一份，不存在"哪个才是正版"的问题；
- 唯一区别是**外壳形式**：桌面端有原生窗口 + 鲸鱼图标 + 托盘常驻 + 开机自启，
  更像一个独立软件；浏览器端就是个网页标签。内核能力完全相同，没有任何阉割。

> 简单说：**你那套"自己的框架界面"就是 dsh 内核提供的完整界面，桌面版只是给它套了个
> 原生窗口。** 生产力该怎么用就怎么用，两边切着用也不会丢东西。

## 五、性能说明（安装版 vs 网页版）

| 指标 | 实测值 |
|---|---|
| 冷启动（服务就绪） | 约 5–10 秒（首次安装后可能 20–30 秒，多为杀软扫描） |
| 热启动（二次启动） | 约 3–6 秒 |
| 后台常驻内存 | 约 170–200 MB |
| 客户端打开速度 | 服务常驻时**瞬时**（本地页面，无需联网） |

优化建议：
- **开机自启**：托盘菜单勾选后，服务随登录后台启动，打开客户端零等待；
- **省内存**：不使用时托盘菜单"停止服务（释放内存）"即可，再次打开自动重启；
- **首次卡顿**：多为 Windows Defender 首次扫描，可把安装目录加入杀软排除名单；
- 客户端使用**原生窗口**（系统 WebView2 内核，无浏览器外壳），窗口与任务栏统一显示
  黑色鲸鱼图标；页面全部由本地服务提供，比网页版省去了网络加载，交互更跟手。

## 六、常见问题

| 问题 | 解决办法 |
|---|---|
| 双击图标没反应 | 首次启动初始化需要几秒；查看安装目录下 `.kkgo\desktop.log` |
| 托盘图标不见了 | 重新双击桌面图标即可恢复托盘 |
| 端口 18632 被占用 | 关闭占用程序后重启；设置环境变量 `DSH_PORT` 可换端口 |
| 杀毒软件/系统提示 | 未签名所致，见安装目录 `docs\数字签名指南.md`；点"仍要运行"即可 |
| 服务异常退出 | 托盘菜单"重启服务"一键恢复 |
| 命令行启动报错：`cannot resolve profile bundle` | **不要用 `npx @deepseek-ai/dsh web`**。npx 会在临时目录重新解析 dsh，找不到全局安装的 profile 与插件。正确命令：`dsh web --host 127.0.0.1 --port 3080`；或直接双击本包附带的 `start-dsh-3080.bat` |

## 七、卸载

控制面板 → 程序 → 卸载 KK Go（或运行安装目录下的卸载程序）。
卸载会移除开机自启注册项，但**保留**你的全部数据（数据目录，默认非 C 盘的 `KK Go Data`；
可在托盘右键「更改数据目录」改到任意盘）。

## 技术信息

- 内置运行时：Node.js v24.22.1（便携版，已随包附带，无需单独安装）
- 桌面版版本：**3.1.5**（内置 dsh 内核 `@deepseek-ai/dsh` 0.2.2-rc.5 + 10个内置插件 + KK Go 品牌插件，内核版本可自由升级）
- 服务地址：`http://127.0.0.1:18632`（客户端专用端口，仅本机可访问，不与 dsh 命令行版冲突）
- 平台要求：Windows 10/11 64 位
