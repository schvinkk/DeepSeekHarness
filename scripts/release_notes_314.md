# KK Go 桌面版 v3.1.4 — 紧急修复版

> 如果你在 v3.1.3 遇到 **「无法创建数据目录 / Microsoft Edge 无法读取和写入其数据目录」** 弹窗，窗口打不开 —— 这一版就是专门修它的。**请直接下载下面的安装包，覆盖安装即可，不用卸载、不会丢数据。**

## 🔧 本次修了什么

### 1. 数据目录路径缺反斜杠（导致 WebView2 弹框、软件打不开）— 致命 bug

- **根因**：选默认数据目录时对盘符根路径做了 `TrimEnd('\\')`，`D:\` 被削成 `D:`；`Path.Combine("D:", "KK Go Data")` 得到 **`D:KK Go Data`** —— 这是 Windows 的「驱动器相对路径」，不是绝对路径。WebView2 拿它当 user data folder，Edge 内核自己弹「无法创建数据目录」模态框，窗口直接废掉。
- **修复**：
  - 保留盘符根路径尾部反斜杠，并用 `Path.GetFullPath()` 规范化；
  - 托盘「更改数据目录」写入的路径、用户自定义配置都强制校验为绝对路径，相对路径一律拒绝；
  - `WebView2` 用户数据目录再兜一层绝对路径检查；
  - 真实写删探针文件验证目录可写，不靠 ACL 猜。

### 2. 覆盖升级会丢数据（隐性风险）

- **修复**：默认数据目录优先复用**安装目录下已存在的 `KK Go Data`**，保证从 3.1.3 覆盖上来时，会话、凭据、配置原样保留。没有旧目录时才去非 C 盘根目录新建。

### 3. 安装包图标没换成鲸鱼

- **根因**：`installer.iss` 缺 `SetupIconFile`，安装程序本体还是 Inno Setup 默认图标。
- **修复**：补上 `SetupIconFile=..\app\whale.ico`，安装器、桌面快捷方式、开始菜单、任务栏、托盘统一使用 DeepSeek Harness 官方鲸鱼图标。

## ✅ 从 v3.1.3 覆盖升级（保姆级）

1. 下载 `KKGo-Setup-3.1.4.exe`。
2. **不用先卸载**。直接双击运行，一路下一步。
3. 安装程序会自动结束正在运行的 KK Go 和它的 Node 内核（只结束本软件自己的进程，不碰你其他 Node 程序）。
4. 装完点完成，重新打开 KK Go —— 数据目录、会话、凭据都在，窗口正常显示。

> 想确认是不是新版：托盘图标右键 → **关于 KK Go**，版本号应显示 `3.1.4`；或右键 → **检查更新**。

## 📦 内置功能/插件清单

- **内核**：DeepSeek Harness（dsh）`0.2.2-rc.5` + 便携 Node `v24.22.1`，随包自带，无需另装。
- **品牌插件**：`dsh-kkgo-brand`（KK Go 专属品牌，已注册为安装依赖）。
- **桌面功能**：原生窗口（WebView2，失败自动回退 Edge 应用窗口/浏览器）、托盘常驻、打开窗口、重启服务、停止服务释放内存、更改数据目录、开机自启、检查更新、打开数据目录、查看日志、关于 KK Go、退出。
- **数据目录**：默认 `安装目录\KK Go Data`（非 C 盘），可用托盘菜单随时改到任意盘；卸载只删程序与快捷方式，不动数据。
- **网络**：首次启动若本地端口被防火墙拦截，会请求一条仅允许本机的放行规则（UAC 确认）。

## 🔏 签名说明

安装包与主程序均使用自签证书做了 Authenticode 数字签名。自签只能降低 SmartScreen 告警，**不能彻底消除**。Edge 下载后如提示「Windows 已保护你的电脑」，点「更多信息」→「仍要保留」即可。要完全消除需商业 OV/EV 代码签名证书。
