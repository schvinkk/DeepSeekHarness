# KK Go 桌面版 v3.1.5 — 修复「服务起不来 / 界面显示 HTTP ERROR 404」

> 如果你点开 KK Go 之后窗口里只有一个 **「找不到此 127.0.0.1 页 / HTTP ERROR 404」**，
> 或者弹窗说 **「内置服务未能正常启动」** —— 这一版就是专门修它的。
> **直接下载下面的安装包，覆盖安装即可，不用卸载、不会丢数据。**

## 🔧 本次修了什么

### 1. 服务起不来，界面只剩 404（致命 bug）

- **根因**：`NODE_OPTIONS` 环境污染。
  启动器会把父进程的环境变量**原样**传给内置的 DSH 内核（node 进程）。
  而很多宿主环境（IDE、终端、自动化宿主、编辑器沙箱）会往 `NODE_OPTIONS` 里塞
  `--require=xxx-shim.cjs`，用来给 node 注入钩子。本机实测 WorkBuddy 的沙箱就注入了
  `node-safe-delete-shim.cjs` —— 它接管了 `fs.rm`。
  DSH 写凭据文件时用的是 `atomic-write`：先抢 `<文件>.lock` 写锁，写完 `rm` 掉锁。
  锁**删不掉** → 下次启动抢不到锁 → 报
  `atomic-write: timed out waiting for the writer lock` → `connection` 插件激活失败
  → `web-runtime` 拿不到 `webServer` 服务 → **端口 18632 从来没监听过**
  → 界面当然只有 404。
  （内层还有第二道伤：DSH 的锁接管机制也会写 `*.lock.takeover-*` 中间文件，
  同样被沙箱拦掉，所以「接管已死进程的锁」这条自救路也走不通。）
- **修复**：
  - 启动器给内核构造环境块时，**强制剥离** `NODE_OPTIONS` / `NODE_REPL_EXTERNAL_MODULE` /
    `ELECTRON_RUN_AS_NODE` / `NODE_ICU_DATA`；同时清理当前进程里的同名变量，
    覆盖「CreateProcess 走继承父进程环境」的回退分支。DSH 是独立服务，不该吃任何宿主的注入钩子。
  - **启动前自动清理残留写锁**：扫数据目录下的 `*.lock` 与 `*.lock.takeover-*`，
    读出锁里的 pid，**只删属主进程已经退出的那些**（活着的实例的锁一律不碰，
    免得两个进程同时写凭据把数据写坏）。
  - 失败提示改成人话：遇到锁超时会直接说「上次退出留下了没清掉的写锁」，而不是笼统的
    「内置服务未能正常启动」。

### 2. 顺带修好的启动自愈

- 之前自愈重启会**无限重试**同一个必然失败的启动。现在锁定失败原因后停止重试，
  并把 DSH 打印的真实原因（不再只是最后一句）挖出来展示。

## 🧪 这次怎么验证的（不是「应该可以」）

不是改完就发。用**真实故障场景**跑了一遍端到端：

1. 在环境里注入 `NODE_OPTIONS=--require=...node-safe-delete-shim.cjs`（复现你的故障）；
2. 故意在数据目录里放两个「属主已退出」的残留锁；
3. 启动 KK Go；
4. 结果：**端口 18632 在 6 秒内被监听**，HTTP 返回 **401**（DSH 的正常鉴权响应，
   证明服务真的活着，不是 404 假页面）；日志逐条打出
   `清理残留锁: .credentials.yaml.lock (pid 999999 已退出)` → `实际监听端口 18632`
   → `服务启动完成` → `服务就绪，打开客户端窗口`。
5. 同时回归了「环境干净」的正常路径，无副作用。

## ✅ 从 v3.1.4 覆盖升级（保姆级）

1. 下载 `KKGo-Setup-3.1.5.exe`。
2. **不用先卸载**。直接双击运行，一路下一步。
3. 安装程序会自动结束正在运行的 KK Go 和它的 Node 内核（只结束本软件自己的进程，
   不碰你其他 Node 程序）。
4. 装完点完成，重新打开 KK Go —— 数据目录、会话、凭据都在，窗口正常显示。

> 想确认是不是新版：托盘图标右键 → **关于 KK Go**，版本号应显示 `3.1.5`。

## 🩹 如果你现在就遇到 404，先试这个（不用等新版本）

关掉 KK Go，然后手动删掉数据目录里这两个残留锁文件，下次启动就能起来：

```
<你的数据目录>\.credentials.yaml.lock
<你的数据目录>\.credentials.yaml.lock.takeover-*
```

默认数据目录是 `KK Go 桌面版安装目录\KK Go Data`。

## 📦 内置功能/插件清单

- **内核**：DeepSeek Harness（dsh）`0.2.2-rc.5` + 便携 Node `v24.22.1`，随包自带，无需另装。
- **品牌插件**：`dsh-kkgo-brand`（KK Go 专属品牌，已注册为安装依赖）。
- **桌面功能**：原生窗口（WebView2，失败自动回退 Edge 应用窗口/浏览器）、托盘常驻、
  打开窗口、重启服务、停止服务释放内存、更改数据目录、开机自启、检查更新、
  打开数据目录、查看日志、关于 KK Go、退出。
- **数据目录**：默认 `安装目录\KK Go Data`（非 C 盘），可用托盘菜单随时改到任意盘；
  卸载只删程序与快捷方式，不动数据。
- **网络**：首次启动若本地端口被防火墙拦截，会请求一条仅允许本机的放行规则（UAC 确认）。
